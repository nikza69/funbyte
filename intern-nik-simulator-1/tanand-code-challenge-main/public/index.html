Funbyte — Office HVAC Simulator API

A black-box office environment simulator exposing sensor readings and split-unit air conditioner control over REST.

Overview

This simulator models a single office room continuously, running an internal simulation loop once per second regardless of API traffic. It exposes the following equipment:

  • Two temperature sensors (A & B) reporting °C, with independent measurement noise
  • Two humidity sensors (A & B) reporting %RH, with independent measurement noise
  • One human activity sensor reporting low, medium, or high, changing automatically every 5–15 minutes
  • One split-unit air conditioner supporting on/off power and a temperature setpoint (cool mode only)
Black-box design: the simulator's actual internal room temperature and humidity are never exposed by any API. Clients only ever see noisy sensor readings derived from that hidden state — exactly as a real office environment would behave to an external monitoring or control system.

API Reference

GET /api/status

Returns all sensor readings and current air-conditioner status. Internal room state is never exposed.

Response

{
  "sensors": {
    "temperatureA": 25.4,
    "temperatureB": 25.2,
    "humidityA": 56.8,
    "humidityB": 55.9,
    "activity": "medium"
  },
  "airConditioner": {
    "power": true,
    "setpoint": 24,
    "mode": "cool"
  }
}
POST /api/ac/on

Turns the air conditioner on.

Response

{
  "success": true,
  "power": true
}
POST /api/ac/off

Turns the air conditioner off.

Response

{
  "success": true,
  "power": false
}
POST /api/ac/setpoint

Sets the AC temperature setpoint. Must be between 18 and 30 (°C).

Request

{
  "setpoint": 23
}

Response

{
  "success": true,
  "setpoint": 23
}

Error response (400 Bad Request)

{
  "success": false,
  "error": "Setpoint must be between 18 and 30"
}
GET /api/ac

Returns the current air-conditioner status.

Response

{
  "power": true,
  "setpoint": 24,
  "mode": "cool"
}

Curl Examples

Get Status

curl http://localhost:3000/api/status

Turn AC On

curl -X POST http://localhost:3000/api/ac/on

Turn AC Off

curl -X POST http://localhost:3000/api/ac/off

Set Setpoint

curl -X POST \
  http://localhost:3000/api/ac/setpoint \
  -H "Content-Type: application/json" \
  -d '{"setpoint":22}'
